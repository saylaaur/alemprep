# Security policy

Do not open a public GitHub issue with credentials, access tokens, student data, screenshots containing student data, or unpublished restricted content.

For a suspected vulnerability, contact the repository owner privately with: a short description, affected route or component, reproduction steps that use synthetic data, and the potential impact. Do not attach secrets or raw authenticated network traces.

The maintainer confirms receipt, assesses impact, rotates any affected credential before discussing history cleanup, and records only redacted evidence in the repository. Production and student accounts are never test fixtures.
