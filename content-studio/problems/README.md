# Генератор задач

Задачи на сайте делаются не по одной, а из **шаблонов**. Шаблон — это одна задача-образец:
условие с переменными, ответ, который считает код, и 4+ неверных варианта из типичных ошибок.
Генератор подставляет разные числа и оставляет только хорошие наборы. Один шаблон даёт до 50 задач.

## Как добавить шаблон

1. Открой файл темы в `templates/` (например `physics_kinematics.py`) или создай новый:
   `<предмет>_<тема>.py` со списком `TEMPLATES = [...]`.
2. Скопируй любой шаблон и поменяй:
   - `id` — уникальный, вида `phys.kin.что-ищем`;
   - `topic` — slug темы из `scripts/data/official-topics.json`;
   - `level` — `easy` / `medium` / `hard` (на ЕНТ примерно 50 / 30 / 20 %);
   - `params` — какие числа подставлять;
   - `where` — отсечь неудобные наборы (необязательно);
   - `answer` — формула ответа;
   - `distractors` — минимум 4 неверных ответа, **каждый — конкретная ошибка ученика** (подпиши комментарием);
   - `text` и `solution` — с `[[переменная]]` и `[[ans]]`; формулы в `$…$`, без кириллицы внутри (слова — через `\text{}`).
3. Собери банк:

   ```
   python3 content-studio/problems/build.py --sample
   ```

   Сводка покажет, сколько задач дал каждый шаблон, и по 2 примера. Меньше 20 — расширь `params` или ослабь `where`.
4. Проверь: `npm test` (тест банка ловит повторы, кириллицу в формулах, неверные темы).

## Форматы ЕНТ

| Формат | Как написать | Пример |
| --- | --- | --- |
| Один верный ответ | `Template(answer=..., distractors=[...])` | `physics_kinematics.py` |
| Несколько верных | `Template(kind="multi", answers=[2–3 функции], distractors=[...])` | `math.calc.increasing-multi` |
| Контекстный блок | `Context(context=..., questions=[...])` в списке `CONTEXTS` | `math.prog.geom-context` |
| Вопрос без чисел (факт) | `fact(...)` — верный ответ строкой и 4 правдоподобные ошибки | `physics_optics.py` |
| Соответствие | обычный `Template`, варианты — строки «1-А, 2-В» | — |

Промежуточные числа для текста (например, $N = a^{x+m} - a^x$) считай в `derived=lambda p: {...}`,
тогда в тексте можно писать `[[N]]`. Помощники для красивой записи: `iv` (промежуток), `union`, `pt` (точка),
`lin` (прямая), `term` и `lead` (слагаемые со знаком внутри формулы).

## Правила

- Ответ всегда считает код. Не вписывай ответ руками.
- Не копируй задачи из чужих тестов: они только образец типа задачи и ловушек.
- Казахский текст в шаблонах — черновик, его вычитывает носитель языка.
- Файлы `lib/problems/bank/*.json` руками не правим — только через `build.py`.
