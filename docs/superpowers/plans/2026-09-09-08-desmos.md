# 08 — Desmos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Встроить Desmos в согласованный дизайн без зависимости основного урока от внешнего SDK.
**Architecture:** Lazy client panel и singleton loader; пресеты связаны с версией задания, локальная иллюстрация/таблица работает без сети. Лицензия и использование данных — отдельный production gate.
**Tech Stack:** Desmos Graphing Calculator API, React, next-intl, Vitest/Playwright.
**Spec:** [архитектура](../specs/2026-09-09-production-pilot-architecture.md), §10, D07.

## Global Constraints

- Существующие design tokens, темы и согласованный дизайн визуализации сохраняются.
- AI и Desmos для школьного контура выключены до отдельных допусков. Сейчас это требование, а не реализованный флаг.
- RU/KK: ключи сообщений в паритете, контент пилота принят человеком по математике и казахскому языку.

**Produces:** DesmosPanel props `{preset:GraphPreset;locale:Locale;enabled:boolean}`; `loadDesmos():Promise<DesmosApi>`; GraphPreset `{id:string;revision:number;expressions:{id:string;latex:string}[];bounds:{left:number;right:number;bottom:number;top:number};fallback:{descriptionKey:string;imagePath:string;table:{x:number;y:number}[]}}`.

- [ ] Read текущей официальной API документации: поддержанная версия SDK/опции `GraphingCalculator`, `setExpression`, `setMathBounds`, `resize`, `destroy`. Зафиксировать конкретную проверенную version в loader, не `latest`, не копировать demo key. Minimal TypeScript interface содержит только используемые официальные методы; не `any` глобально.
