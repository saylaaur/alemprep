# Видеоуроки (раздел «Видео»)

Страница урока: слева видео, под ним 12–15 задач, ниже пробник строго по теме; справа — страницы книги-конспекта.
Маршруты: `/videos` (список) и `/videos/[lesson]` (урок).

## Правила
- **Тема закрыта**, когда решены все задачи под видео (верно или нет). Тогда открывается пробник по теме.
- Пробник: ответы видны только в конце, потом разбор каждого вопроса. Лучший результат запоминается.
- Варианты ответов перемешиваются одинаково на сервере и в браузере (`lib/lessons/shuffle.ts`).
- Прогресс пока хранится в браузере (`lib/lessons/progress.ts`). Запись в базу — следующий шаг:
  таблица уроков, импорт задач в `questions`, попытки в `attempts`.

## Как добавить урок
1. Видео и постер положи в `public/lessons/<id>.mp4` и `<id>.jpg` (позже — Supabase Storage).
2. Создай `lib/lessons/data/<id>.json` (формат — `lib/lessons/schema.ts`, пример — `newton-laws.json`):
   12–15 задач и минимум 8 вопросов пробника, формулы в `$...$`, русские буквы внутри формул — только в `\text{}`.
3. Добавь файл в `RAW` в `lib/lessons/catalog.ts`.
4. `bookSlug` — книга-конспект из библиотеки (`docs/books-plan.md`); она показывается справа.
5. `npm test` проверит формат, уникальность id и что пробник не повторяет задачи.
6. Казахский: поле `kk` с `title`, `problems`, `mock`. Пока `kk` не заполнен, показываются русские задачи.

## Звуки
`lib/sound/ui-sounds.ts` рисует короткие тона через Web Audio — файлов нет. Звук касания включён для всех кнопок и ссылок
(`UiSoundListener` в `AppShell`); у ответов на задачи свои звуки (`data-sound="off"` отключает общий).
Переключатель — в боковом меню и в шапке урока; выбор хранится в `localStorage` (`alemprep:sound`).

## Демо для показа
`node demo/lesson-demo/build.mjs <папка>` собирает автономную страницу (`index.html` + видео + постер) из тех же компонентов.
