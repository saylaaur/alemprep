# Книги-конспекты и напоминания

## Как это работает
- **Книга** = конспект одной подтемы официальной темы НЦТ. Полный план — `docs/books-plan.md` (186 книг).
- Ученик **получает книгу** после урока (кнопка «Получить книгу» на странице книги; позже — автоматически после видеоурока).
- **Повторения:** через 1, 3, 7, 10, 14, 30 и 60 дней — это промежутки *между* повторениями. Логика — `lib/books/schedule.ts`.
  - Вспомнил половину и больше → следующий промежуток.
  - Меньше половины → шаг назад на один промежуток (не раньше первого).
  - Раньше срока перечитать можно, график не меняется. После 7-го успешного повторения книга «выучена».
- Записи ученика (`user_books`, `book_reviews`) пишет только сервер (service_role); браузер может только читать свои строки.

## Как добавить готовый конспект
1. Создай `scripts/data/books/<slug>.json` с полями `ru` и (по возможности) `kk` — формат в `lib/books/content.ts`, пример — `newton-laws.json`.
   Формулы — в `$...$`; русские/казахские буквы внутри формул — только в `\text{...}` (тест это проверяет).
2. `npm test` — проверит формат и slug.
3. Новая миграция с обновлением: `UPDATE public.books SET content_ru = '...'::jsonb, content_kk = ... WHERE slug = '<slug>';`
   (миграцию 0042 после применения не меняем).

## Telegram-напоминания: настройка (один раз)
1. В Telegram у **@BotFather**: `/newbot` → получи токен и имя бота.
2. В Vercel → Settings → Environment Variables добавь:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` — имя бота без @
   - `TELEGRAM_WEBHOOK_SECRET` — любая длинная случайная строка
   - `CRON_SECRET` — ещё одна случайная строка (Vercel Cron подставит её сам)
   - `SUPABASE_SERVICE_ROLE_KEY` — уже должен быть
3. Подключи вебхук (подставь свои значения):
   ```
   curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
     -d "url=https://<домен>/api/telegram/webhook" \
     -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>" \
     -d 'allowed_updates=["message"]'
   ```
4. Задеплой. `vercel.json` запускает `/api/cron/book-reminders` каждый день в 04:00 UTC = **09:00 по Казахстану**.

Ученик: «Настройки» → «Подключить Telegram» → откроется бот → «Start». Отключить — `/stop` в боте или кнопка в настройках.
Если ученик заблокировал бота, привязка снимается автоматически.

## Если сделаем мобильное приложение
`lib/telegram/reminders.ts` не зависит от Telegram: в `send` можно подставить отправку push-уведомлений, а данные (`loadDue`) останутся теми же.
