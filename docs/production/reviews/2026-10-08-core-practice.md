## Подтверждённые проблемы и изменения

1. Выбор следующего задания не учитывал историю ученика. На регрессионном
   примере 17 последовательных выдач давали только 12 разных задач.
   Теперь сначала выбираются семейства, отсутствующие в последних 200
   trusted practice сессиях этого ученика в этой теме. RU и KK используют
   общую историю семейства. Когда весь доступный набор уже встречался,
   выбор идёт из более давней половины. Ошибка чтения истории сохраняет
   прежний выбор, чтобы необязательная персонализация не блокировала занятия.
2. После ответа показывалась буква правильного варианта без пометок у
   вариантов. Для single/multi правильные варианты теперь отмечены зелёным
   и галочкой, выбранные неверные — красным и крестиком. Источник — сохранённый
   сервером результат после ответа; до ответа ключ не передаётся.
3. Дополнительно к патчу Claude добавлены RU/KK подписи для screen reader.
   Исправлена гонка в новом E2E: тест больше не запускает пятую сессию перед
   удалением тестового пользователя. Код продукта ради teardown не менялся.

## Границы изменения

Это улучшение последовательной практики, не атомарный запрет повторов между
вкладками: два одновременных запроса с разными operation ID могут выбрать одно
семейство. История ограничена 200 сессиями, а тема с одной задачей повторяется
естественным образом. Это не меняет правила оценивания и подсчёта отчётов.

Replay остаётся перед выбором следующего задания. История читается только на
сервере с фильтрами текущего ученика и темы. RLS, RPC, миграции, опубликованный
контент и hosted настройки не менялись. Для установки SQL выполнять не нужно.
