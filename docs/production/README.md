## Какой результат считаем достаточным для двух школ

Ученик индивидуально входит, получает назначенные проверенные задания на RU или KK, решает и получает подтверждённое сохранение. Повтор запроса не портит прогресс. Учитель видит свою группу и может объяснить, кто приступил, кто завершил и какие темы затрудняют. Команда получает журнал изменений и ошибок. Управлению образования выдаётся воспроизводимый агрегированный отчёт с честными знаменателями. Школа имеет резервный материал и контакт поддержки. Размещение, участие детей и доступы приняты ответственными людьми.

Под «production» здесь понимается настоящий ограниченный школьный запуск с защитой данных и эксплуатацией. Национальный масштаб, все предметы для всех классов и полная LMS — отдельный этап.

**Первой брать E01.** Независимо от coding пути владелец начинает D01–D07, методист готовит C01; доступ к ученикам не нужен для реализации synthetic fixtures. O01 допускает ранний отдельный default-off AI commit до L03, чтобы требование появилось в коде сразу; полная задача закрывается после интеграции.

Порядок одного последовательного исполнителя: E01 → E02 → E03 → L01 → L02 → L03 → L04 → C01 → C02 → S01 → S02 → S03 → S04 → O01 → R01 → R02 → R03 → U01 → U02 → U03 → O02 → O03 → O04 → P01 → P02 → P03. V01/V02 выполняются после U01 и до P01, если нужен Desmos в первом уроке; без лицензии не задерживают основной урок. D02–D06 и человеческая проверка контента идут параллельно разработке, но без них P01/P02 не закрываются.

Распределение по моделям — рабочее решение команды, не гарантия качества. Terra medium: интерфейсы по готовым DTO, i18n, документация, представление метрик. Terra high: SQL, транзакции, auth, миграции, конкурентность. Astra: проверка схемы/инвариантов перед L04, S04, R03, O04 и P01, а также конкретные неразрешённые противоречия. Повышать модель после двух воспроизводимых неудачных исправлений, передавая diff и failing case; не просить заново планировать весь продукт.

## Ворота допуска

| Gate | Требование | Доказательство / ответственный |
| --- | --- | --- |
| G0 Release | Точный commit, схема/миграции, CI и alias согласованы | E01/E03, технический ответственный |
| G1 Данные и вход | D02/D03/D04 приняты; способ входа реально работает в школе | Закрытый decision register, R03, организатор/оператор |
| G2 Целостность | Нельзя подделать свой результат, повтор не даёт дублей; чужая школа закрыта | L04/S04 реальные REST/RPC + concurrent tests; Astra |
| G3 Контент | 100% выбранной программы RU/KK имеет проверку метода/языка/прав | C01/C02, методист; нет скрытого fallback в школьном уроке |
| G4 Учитель/отчёт | Кабинет работает; контрольные цифры отчёта сходятся | S03/R02 golden fixtures + учительская репетиция |
| G5 Сеть/устройства | Общий ПК, телефон, плохая сеть, logout/retry приняты | U03 browser evidence + школа |
| G6 Эксплуатация | Нагрузка, бюджет, тревоги, восстановленная копия, ответственные | O03/O04, принятое D05/D06 |
| G7 Выпуск | P01 на точном candidate, нет открытых P0/P1, есть безопасный rollback | Astra + владелец принимает запуск |
| G8 Desmos | Лицензия/ключ/языки/сеть/данные приняты | V02; без G8 модуль OFF, G0–G7 всё ещё позволяют урок |

Отдельное нарушение: при известной несовместимости действующих grants и текущего production нельзя называть G0 зелёным, даже если лендинг отвечает 200.

## Объём и сроки

Ориентир планирования после чтения кода: **3–5 недель плотной разработки и приёмки одним исполнителем с ревью**, плюс внешние ожидания. Это не обещание даты. Основа release/DB 5–8 рабочих дней; школы/отчёты 5–8; контент/UI/сеть 3–6 с параллельной работой методиста; операции/репетиция 3–5. Путь через новое размещение/перенос Auth может добавить 1–2 недели и зависит от провайдера. После E02 и L02 переоценить по фактической скорости.

Можно раньше показать synthetic демонстрацию teacher и программы; это не разрешение подключить детей без остальных ворот. Если дата школы оказывается раньше — сокращаем число тем, добровольно выключаем AI/Desmos, ограничиваем группы; не снимаем RLS, аудит, backup и проверку контента.

Предположение нагрузки N=60/2N=120 заменяется реальным максимальным числом одновременных учеников после ответа школ. Пока нет даты старта и устройств, нельзя честно назвать точную стоимость инфраструктуры. Бюджет включает hosting + DB/Auth + backups + monitoring + домен + возможную лицензию Desmos; AI в школьном контуре 0 вызовов по умолчанию. Резерв расходов согласуется до активации платного тарифа.

«Потратить все лимиты» не является измеримой сметой токенов: перепланирование и повторный полный контекст обычно дороже выполнения небольших задач. На первые E01/E02 записать число проходов и фактическое потребление доступного окна; дальше прогнозировать по своей статистике. Не обещать процент/цену без измерений и не путать API token prices с лимитами подписки Codex.
