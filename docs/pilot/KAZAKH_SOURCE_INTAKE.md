# Образец казахского контента — карточка приёмки

Основание: [план от 20.09](../superpowers/plans/2026-09-20-kazakh-pilot-rebaseline.md). Статус: форма подготовлена; поставщик, цена, образец и проверяющий ещё не получены. Это не разрешение на закупку/публикацию.

## До покупки партии

| Что собрать | Критерий решения |
| --- | --- |
| Поставщик, предмет, год, один образец, цена 1 и 10 вариантов | Можно оценить соответствие первым темам; не покупать объём вслепую |
| Условия использования и контакт правообладателя | Понятно, разрешены ли показ на платформе, переработка и обработка внешним API |
| PDF/сканы, таблицы/диаграммы, ключи, решения | Материал полностью читается; никакой реконструкции отсутствующих рисунков |
| Учитель/редактор | Есть человек для математического решения и казахского языка; модель не подписывает human review |
| Классы и 2–3 темы первых занятий | Подборка соответствует ученикам, а не только структуре купленных пробников |

## Реестр закрытой sample-партии

Хранить реальные тексты/изображения, персональные контакты и документы об условиях использования вне Git. В репозитории — только synthetic примеры и агрегаты.

Для каждой задачи записать: source ID/hash, номер/страницу, topic, тип, наличие контекста/медиа, исходный ключ, независимо решённый ответ, origin, draft hash, ошибки извлечения, результат предметной и языковой проверки, затраченные минуты, accepted/rejected и причину. Подпись редактора относится к конкретному hash; после изменения нужна новая проверка.

Сводка: рассмотрено / принято / отклонено по каждой теме; причины брака; число независимых задач и семейств отдельно; сумма покупки и API; часы редактора. Умножение вариантов не считать расширением тематического покрытия.

Решение после sample: использовать оригиналы по разрешённым условиям; подготовить собственные задания; точечно перевести проверенные RU; либо заменить источник. Следующую закупку оценивать по числу дополнительных пригодных задач нужных тем.
