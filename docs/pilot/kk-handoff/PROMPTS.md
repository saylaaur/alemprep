# Промпты для Claude

## 1. Новый чат: создание задач

Скопируй текст ниже и прикрепи README, batch.schema.json, example-batch.json.

```text
Ты помогаешь подготовить казахский контент AlemPrep — платформы подготовки к ЕНТ. Через несколько дней планируется сопровождаемый урок в сельской школе. Твоя работа — создать небольшой качественный банк, а не писать сайт, SQL или обращаться к БД.

Прочитай приложенный README и JSON Schema. Не считай примеры в example-batch.json принятыми заданиями. В результате должны быть собственные AI-assisted задачи на казахском языке, не копии конкретных пробников и не «официальные задания НЦТ».

Рабочая тема: math / linear-quadratic-rational-equations. Первый пакет — 5 задач: 3 линейных и 2 квадратных уравнения, 4 варианта A–D, один правильный. Locale kk, type single, difficulty 2 или 3. Используй разные проверяемые навыки, целые/простые рациональные ответы. Никаких необходимых внешних изображений и контекстов. Все объяснения также на казахском.

Для каждой задачи сначала найди решение и проверь его подстановкой; затем составь правдоподобные ошибочные варианты. Проверь, что среди них ровно один правильный. При вопросе обо всех корнях вариант ответа должен содержать полное множество корней. Не создавай неоднозначных или эквивалентных вариантов. Учитывай ОДЗ там, где она нужна.

В JSON отдай краткое учебное объяснение решения, а не скрытый ход рассуждений. Формулы оформляй через $...$, обратные косые черты корректно экранируй для JSON. Если есть таблица, передай её структурированным table-блоком. Полное условие должно оставаться доступно при использовании stem_blocks.

Происхождение для новых задач — authored, rationale честно описывает AI-assisted создание по навыку. Не выдумывай источник, лицензию или проверяющего. Не добавляй approved/human_review. При сомнениях заполняй issues. Близкие числовые варианты имеют один family_key. Локальные ID стабильны; при исправлениях меняй revision.

Сначала коротко перечисли выбранные пять навыков, затем создай скачиваемый batch.json, строго по схеме. Если создание файла недоступно — один валидный JSON-блок. Не запускай платные API и не проси ключи. Остальные 25 кандидатов будем делать следующими партиями по пять; сейчас не генерируй все сразу.
```

## 2. Новый независимый чат: проверка математики

Передай ID, условие, stem_blocks и options, убрав correct и explanation. Не прикрепляй исходный batch целиком в этот чат до независимого решения.

```text
Реши приложенные математические задачи независимо. Исходного ключа у тебя нет. Для каждого ID выдай: полученный ответ, ID подходящего варианта, краткое проверяемое решение, проверку подстановкой или альтернативным способом, и список ошибок/неоднозначностей. Проверь ВСЕ варианты: не может ли быть двух правильных или ни одного? Для квадратных уравнений проверь оба корня; для дробей — допустимость знаменателя. Укажи отсутствующие данные, если они есть. Не додумывай условие. Сохрани результат как solutions-independent.md. Не утверждай, что это human review.
```

После этого сравни результаты с ключом автора. При несовпадении не проси просто согласиться с ключом: разбери конкретную ошибку, исправь задачу и повтори проверку.

## 3. Отдельная языковая вычитка

```text
Проверь казахский текст условий, вариантов и объяснений для школьников старших классов. Сохраняй математический смысл, знаки отрицания, числа, единицы и то, что требуется найти. Для каждого ID дай: проблема, предлагаемая правка, влияет ли она на математический смысл. Не меняй числа/ключи молча. Не придумывай уверенность: спорные термины вынеси в вопросы человеку. Не выдавай результат за проверку учителя или носителя языка.
```

## 4. Исправление и выдача финального пакета

```text
Учти перечисленные замечания к ID. Не меняй задачи без замечаний. Сохрани ID/family_key, увеличь revision исправленных задач, повтори проверку каждого варианта и объяснения. Выдай batch.json целиком без комментариев/многоточий, отдельно changelog по ID. Все нерешённые вопросы оставь в issues. Не выставляй статус approved: это сделают люди после проверки конкретной версии.
```
