## Контрольные вопросы

- [ ] RU и KK задают одну и ту же задачу; нет потери отрицания/ограничений.
- [ ] Формулы, числа, переменные, единицы, code и URL не испорчены.
- [ ] Сохранены тип, IDs, порядок/количество вариантов, структура таблиц.
- [ ] Matching ключ совпадает с переводом исходного right на том же индексе.
- [ ] Ключ согласуется с независимым решением, объяснение не пропускает ошибки.
- [ ] Общий контекст переведён полностью и соответствует исходнику.
- [ ] Русский текст внутри формулы/изображения обработан или записан как issue.
- [ ] Не придуман human reviewer, НЦТ-приёмка или право публикации.
- [ ] У unresolved задач решение changes-required; они не пойдут школьникам.
