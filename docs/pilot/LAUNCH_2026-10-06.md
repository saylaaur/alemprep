# Запуск первого класса: 06.10.2026

> **Актуально09.10:** текущие approved counts, порядок самостоятельного пилота, AI-review exception и действия запуска — в [PILOT_LAUNCH.md](PILOT_LAUNCH.md). Датированные статусы ниже — история, не команда повторно выполнять старые миграции.

Это инструкция для ограниченного пилота самостоятельной подготовки. Первый
запуск — небольшая русскоязычная группа и доступная принятая тема. При последней
hosted проверке в банке было 17 принятых RU задач по прогрессиям и 0 KK задач.
Это ещё не полный курс подготовки к ЕНТ. Казахский интерфейс и графический
инструмент доступны; казахские задания требуют отдельной приёмки перевода.

## Что вошло в релиз

- Встроенные графики на SVG: отдельный инструмент и графики к подходящим задачам.
  Внешний Desmos и платный ключ для них не нужны. Для прогрессий график может
  отсутствовать: это не ошибка, визуализация подходит не каждому условию.
- Выбор Google-аккаунта при каждом новом входе. На общем компьютере всё равно
  нужно нажимать «Выйти» после занятия: открытая сессия сама не сменит ученика.
- Ссылка вступления в класс, её копирование и заполненный код после входа.
  Вступление доступно до онбординга. При отмене входа можно повторить попытку,
  сохранив ссылку класса.
- Серверный флаг `PILOT_TOPICS_ONLY`: меню и страницы ведут в темы; пробник,
  диагностика и недельный тест скрываются. Их legacy результаты не входят
  в подтверждённый учительский отчёт.
- Темы с доступными заданиями показываются раньше пустых.

Новых миграций в этом наборе нет. Уже применённые 0034–0040 не менять и
повторно не запускать ради этих патчей. Нельзя принимать источник
`0209018e-2477-4d29-b5ce-18df2fa6d893`: неверный ключ ответа.

## 1. Подготовить деплой

В Vercel → AlemPrep → Settings → Environments → Preview выбрать именно ветку
`codex/trusted-practice`, если репетируем на preview. Проверить:

| Переменная | Значение / назначение |
| --- | --- |
| `LEARNING_V1_ENABLED` | `true`: принятый банк и подтверждённая запись ответов |
| `PILOT_TOPICS_ONLY` | `true`: работа учеников через темы |
| `SUPABASE_SERVICE_ROLE_KEY` | существующий ключ проекта, Type **Secret**, только на сервере |
| `NEXT_PUBLIC_SUPABASE_URL` | проект `euypaocjzcqlapfilrak` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | публичный ключ того же проекта |
| `NEXT_PUBLIC_SITE_URL` | `https://alemprep.vercel.app` |

Ключ service-role не присылать в чат, не коммитить и не переименовывать с
`NEXT_PUBLIC_`. Значение брать из своей `.env.local` или настроек того же
Supabase проекта. Наличие в локальном файле не означает наличие в Vercel.

Region Functions — Frankfurt (`fra1`); System Environment Variables включены.
После изменения env нужен **новый deployment / Redeploy** выбранного Preview.
Дождаться Ready и проверять один стабильный URL:

`https://alemprep-git-codex-trusted-practice-saylaaurs-projects.vercel.app`

Не раздавать ученикам URL отдельного deployment: Google PKCE cookie и точный
callback должны принадлежать одному домену. Не смешивать preview и production.
После merge код на `main` может автоматически задеплоиться, но флаги Preview
в Production сами не переносятся. Включать пилотные флаги в Production только
после успешной репетиции и проверки серверного ключа там; затем Redeploy.

## 2. Проверить Google-вход

Supabase → Auth → URL Configuration: Site URL остаётся production.
Для выбранного домена должен существовать точный `/auth/callback`, без wildcard
на другие проекты. Новый код возвращает произвольную ссылку класса через
временную HTTP-only cookie; добавлять отдельный callback для каждого кода
класса не нужно. Старые разрешённые RU/KK callback URL можно оставить.

Ранее сохранён token refresh limit: 1800 за 5 минут. Это помощь общему школьному
IP, а не доказательство нагрузочной ёмкости. Остальные ограничения не отключать.

В Google Cloud → Google Auth Platform → Audience ранее был статус **Testing**.
До раздачи ссылки проверить вход реальным аккаунтом ученика, не аккаунтом
разработчика. Если доступ ограничен тестовыми пользователями, для малого
прогона добавить согласованные аккаунты в Test users или завершить Branding
и публикацию приложения. Не указывать выдуманные ссылки privacy/terms и не
считать переключение Production выполненным, пока консоль его не подтвердила.

## 3. Создать реальный класс

Нужны название школы, класс, email учителя и email координатора. Учитель и
координатор сначала сами входят через Google на выбранном сайте.

Использовать [START_FIRST_CLASS.md](START_FIRST_CLASS.md) и приватную заполненную
копию [bootstrap-first-class.sql](bootstrap-first-class.sql). Выполнить её в SQL
Editor нужного проекта. Копию с персональными данными не коммитить. Эта операция
привязывает права к реальным аккаунтам; тестовых учителей в hosted БД не создавать.

Учитель: `/ru/teacher` → свой класс → «Создать новый код» →
«Скопировать ссылку». Отправить её только своему классу. Код действует 72 часа,
максимум 100 вступлений; при истечении создать новый, существующие ученики останутся.

## 4. Одна обязательная репетиция

1. Учитель входит и видит свой класс. Случайный ученик не получает кабинет учителя.
2. Один ученик открывает ссылку на своём телефоне или в отдельном браузере,
   выбирает собственный Google-аккаунт и видит уже заполненный код.
3. Ученик нажимает «Вступить», проходит онбординг, открывает
   «Предметы → Математика → Прогрессии» и отвечает на одну задачу.
4. Обновить страницу: ответ и результат сохранены. Не появилось второй попытки.
5. Учитель обновляет отчёт: у этого ученика ровно одна новая попытка и её баллы.
6. На ширине 390 px проверить графический инструмент: смена функции, масштаб,
   отсутствие горизонтального скролла. График к задаче проверить на принятой
   подходящей задаче, если такая есть; не принимать непроверенный контент ради smoke.
7. Проверить, что пробник/диагностика/недельный тест ведут в «Предметы» при
   включённом пилотном флаге. После проверки общего компьютера нажать «Выйти».

Только после этих шагов начинать с 10–20 учеников и человеком на связи.
Это размер первого сопровождаемого прогона, не результат нагрузочного теста.
Если ответ или отчёт не сохраняется, не расширять группу: записать время,
код ошибки и URL, исправить причину и повторить репетицию.

«Запускаем ограниченный русскоязычный пилот самостоятельной подготовки.
Есть упражнения, сохранение ответов, кабинет учителя и встроенные графики.
Сначала связываем школу и класс и проверяем одного ученика от входа до отчёта.

казахский контент идут следующим этапом. Полный двуязычный курс пока не обещаем».

## Честные ограничения

Автотесты на локальной БД не заменяют проверку реального Google-входа,
Vercel env и отчёта на hosted БД. Казахские переводы и новые строки онбординга
должен прочитать человек со знанием языка. Числовой графический движок —
вспомогательная визуализация, а не доказательство полного множества решений
произвольного выражения. QR, новые отчётные экраны и дополнительные предметы
не входят в этот срочный набор.
